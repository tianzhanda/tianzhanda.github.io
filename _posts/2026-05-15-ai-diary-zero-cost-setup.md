## 缘起：为什么要做这件事

每天都有大量的 AI 新闻在发生——OpenAI 发了新模型、Google 更新了 Gemini、哪个团队又开源了什么。信息是碎片化的，但很少有人去**记录和串联**。

而我想要的不是又一个新闻聚合站。**AI启智录** 的核心使命是四件事：

- **观测** — 持续追踪 AI 领域的关键事件，不错过重要的里程碑
- **记录** — 以日期为锚点，把每一天的真实进展沉淀下来，形成可回溯的时间线
- **思考** — 不只是搬运新闻，而是由 AI 带着观点去解读、去评价、去串联事件背后的逻辑
- **见证** — 用时间积累，描绘一条 AI 进化的轨迹曲线，让后来者能回看这个时代

听起来很大，但做起来其实很简单——一个每天 23:00 自动运行的定时任务，一个 GitHub Pages 静态站，一颗 Cloudflare KV 存储。**零成本。**

## 技术架构

整个网站**零成本**，不依赖任何付费服务：

| 组件 | 方案 | 费用 |
|------|------|------|
| 前端 | GitHub Pages | 免费 |
| 后端 API | Cloudflare Workers | 免费 |
| 数据存储 | Cloudflare KV | 免费 |
| AI 生成 | OpenRouter 免费模型 | 免费 |
| 评论系统 | Giscus | 免费 |
| 域名 | github.io 子路径 | 免费 |

### 架构图

```
┌─────────────────────────────────┐
│   GitHub Pages (前端静态站)       │

└──────────────┬──────────────────┘
               │
┌──────────────▼──────────────────┐

│   → 存入 KV                      │
└─────────────────────────────────┘
```

## 核心流程

每晚 23:00（北京时间），Cloudflare Worker 的 cron 定时任务被触发：

1. **爬取新闻** — 同时爬取 5 个源
   - Hacker News（国际科技社区风向标）
   - Reddit r/MachineLearning（AI 研究者讨论热点）
   - TechCrunch AI（科技媒体）
   - 机器之心（中文 AI 资讯）
   - 知乎 AI 话题（国内讨论热度）

2. **AI 生成日记** — 把新闻素材喂给 OpenRouter 的免费模型，模型会选出最有价值的 1-3 条，写出有观点、有态度的日记，输出结构化 JSON

3. **存储到 KV** — 日记以日期为 Key 存入 Cloudflare KV

4. **前端展示** — 用户访问网站时，前端通过 API 获取日记数据
   - 日历组件标记有日记的日期
   - 搜索框全文检索
   - Giscus 评论按日期独立开贴

## 定价

**$0/月。** 全程零成本，但如果你想更稳定或者跑更复杂的模型，可以买个域名（几十块/年），或者充点 OpenRouter 额度。
